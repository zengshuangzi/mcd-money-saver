# 麦麦省钱助手（McD Money Saver）

> 花最少的钱，吃得麦满意。🍔

「麦麦省钱助手」是一个基于**麦当劳 MCP 能力**构建的智能省钱 Skill，帮助你把散落在各处的优惠券、麦麦省券、积分和套餐组合自动盘清楚，算出每一单最省钱的点法。

本作品为 **麦当劳程序员节创意开发大赛** 参赛项目，使用腾讯 **WorkBuddy** 辅助开发。

---

## 💡 它解决什么问题

每次点麦当劳，你是不是也纠结过这些问题？

- 手里攥着好几张券，哪张最划算？能不能叠加？
- 麦麦省又有新券可以领了，我领没领？
- 预算只有 30 块，该怎么点才能吃饱又不超支？
- 想控制热量，又不想错过优惠。

**麦麦省钱助手把这些事全包了**：先摸清你的券 → 帮你领 → 比价 → 算最优组合 → 给你一个明确的"省了多少钱"的答案。

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🎫 智能领券 | 一键领取麦麦省所有可领优惠券（`auto-bind-coupons`） |
| 🧾 最优组合 | 结合优惠券，算出"省钱最多"的套餐/餐品组合 |
| 💰 预算点餐 | 固定预算内，找最省钱又不超支的点法 |
| 🔥 热量搭配 | 控制热量的同时，仍帮你找最优价格 |
| 📊 积分查询 | 查积分余额，结合积分兑换省钱 |

## 🧠 工作原理

基于麦当劳 MCP 的多工具编排，流程如下：

```
查附近门店 → 查我的券/可领券 → 领券 → 查菜单 → calculates-price 比价 → 输出最优方案
```

详细工具调用说明见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md)。

## 📦 安装方法

### 前置条件

1. 申请麦当劳 MCP Token：前往 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，手机号登录 → 控制台 → 激活，一键复制 Token。
2. 一个支持 Streamable HTTP 的 MCP Client（推荐 **WorkBuddy**）。

### 接入麦当劳 MCP

在 MCP Client 中添加如下配置（把 `YOUR_MCP_TOKEN` 换成你的真实 Token）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 脱敏示例见 [`mcp-config.example.json`](./mcp-config.example.json)。

### 安装本 Skill

- **WorkBuddy**：将本仓库中的 `SKILL.md` 放入你的技能目录，或在对话中直接导入。
- 其他 Client：参考其 MCP Skill 导入方式，将 `SKILL.md` 作为 Agent 提示词加载。

## 🚀 使用示例

### 示例 1：预算内最省钱

> 用户：我只有 30 块，想吃顿麦当劳。
>
> 麦麦省钱助手：附近 3 家门店中，XX 店可用「满 30 减 5」券。推荐「麦辣鸡腿堡套餐」原价 ¥35 → 用券后 ¥30，帮您省了 ¥5，还送一杯可乐。要下单吗？

### 示例 2：薅羊毛

> 用户：看看我能领什么券。
>
> 麦麦省钱助手：已为您一键领取 3 张麦麦省券：「大薯条买一送一」「早餐卡 5 折」「麦辣鸡翅 8 折」。其中「早餐卡 5 折」用在早餐套餐上最划算。

### 示例 3：热量可控

> 用户：控制在 500 大卡以内，能省就省。
>
> 麦麦省钱助手：为您搭配「双层吉士汉堡 + 零度可乐」共 480 大卡，叠加「满 20 减 3」券后 ¥19，比单点省了 ¥6。
